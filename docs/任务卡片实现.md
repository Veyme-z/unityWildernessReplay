> 适用范围：`Assets/Scripts/FX/TaskCardBadge.cs`、`Assets/Scripts/FX/TaskBadgeManager.cs`、`Assets/Scripts/FX/ReplayCinematic.cs`（均 ReplayEntry 挂载）。

## 一、更换素材（先看这个）

> 不用改代码；只有 **WebGL 需重新导出 Build**（编辑器进 Play 即生效）。
> 想**改名字/改路径**才需要同步改代码常量（见下表「代码常量」）。
> 所有视频都必须 **H.264/avc1** 编码（WebGL 浏览器只能解这种；`mp4v` 在浏览器黑屏）。

本项目用到 3 个视频，**全部是"同名同路径覆盖即换"**：

| 用途 | 文件（必须同名同路径覆盖） | 代码常量（改名/改路径时改这里） | 播放方式 |
|------|----------------------------|-------------------------------|----------|
| 任务卡片「破解中」循环 | `Assets/StreamingAssets/TaskVideos/working.mp4` | `TaskCardBadge.WORKING_VIDEO = "TaskVideos/working.mp4"` | 循环，跟回合走（卡片内） |
| 全屏剧情：任务点1领取 | `Assets/StreamingAssets/plane.mp4` | `ReplayCinematic.TASK1_VIDEO = "plane.mp4"` | 播一遍自动关（领取回合） |
| 全屏剧情：入夜首回合 | `Assets/StreamingAssets/ufo.mp4` | `ReplayCinematic.NIGHT_VIDEO = "ufo.mp4"` | 播一遍自动关（每个自然入夜） |

> ⚠️ 常量里的路径都是**相对 `StreamingAssets/`** 的，代码会自动拼全（编辑器绝对路径 / WebGL 相对正斜杠）。所以**文件名必须对**，而且文件夹位置别放错：`working.mp4` 在 `TaskVideos/` 子目录；`plane.mp4`/`ufo.mp4` 在 StreamingAssets **根目录**。

任务卡片 4 个状态，**只有 Working 是视频**（卡片内唯一视频），其余 3 个状态都是**静态图片**（各展示 2 回合）：

| 状态 | 素材类型 | 文件位置 | 说明 |
|------|----------|----------|------|
| Intro（领取任务） | 图片 | `Assets/Resources/Sprites/claim.png` | 展示 2 回合 |
| Working（破解中） | 视频 | `Assets/StreamingAssets/TaskVideos/working.mp4` | 循环播放，跟回合走 |
| Success（解锁成功） | 图片 | `Assets/Resources/Sprites/unlock_success.png` | 展示 2 回合后淡出销毁 |
| Fail（解锁失败） | 图片 | `Assets/Resources/Sprites/unlock_fail.png` | 展示 2 回合后淡出销毁 |

### 1. 换图片（Intro / Success / Fail）

直接替换 `Assets/Resources/Sprites/` 下的 `claim.png` / `unlock_success.png` / `unlock_fail.png`（**保持文件名**），Unity 自动导入，进 Play 即生效。
- 图片**必须放 `Resources/`**：`Resources.Load` 是**同步**加载，WebGL 也随 Build 打包进产物，无需异步、不会出现"图片加载中"的中间态。
- 缺图不崩：自动回退纯色 + 文字（Intro 兜底 task.png；Working 蓝「破解中」/ Success 绿「✓ 通过」/ Fail 红「× 失败」）。
- 图片建议尺寸：与卡片底板比例匹配即可（当前 claim 1024²、unlock 2048×1024），WebGL 别用超大图（显存占用）。

### 2. 换 Working 视频

把新视频命名为 `working.mp4`，替换 `Assets/StreamingAssets/TaskVideos/working.mp4`。编辑器进 Play 即生效；**WebGL 需重新导出 Build**。

- **格式硬性要求：H.264/AAC（编码标记 `avc1`）**。浏览器 `<video>` 只认 H.264/VP8/VP9/AV1/HEVC；如果视频是 `mp4v`（MPEG-4 Part 2），编辑器能放但**浏览器解不出帧 → 一直显示占位图**。
- **检查编码**（无需 ffmpeg）：`grep -aoE 'avc1|mp4v' 你的视频.mp4`，输出含 `mp4v` 就要转码。
- **转码**（Windows 自带 Media Foundation），脚本在 `D:\work\WildernessReplay\_transcode.ps1`：
  ```bash
  powershell -File D:\work\WildernessReplay\_transcode.ps1 -Dir <视频目录> -Targets working.mp4
  ```
  生成 `working_h264.mp4` 后替换。
- 时长建议：Working 是循环素材，任意时长（显示跟回合走，播完重头）。

### 3. 换全屏剧情视频（plane.mp4 / ufo.mp4）

全屏剧情由 `ReplayCinematic` 负责：**任务点1领取 → plane.mp4**、**每个自然入夜首回合 → ufo.mp4**。替换方式同上：**同名覆盖 `Assets/StreamingAssets/` 下的文件**（两段当前均 1280×720/24fps/5.13s；plane≈6.4MB、ufo≈8.7MB）。

- **触发**：都是**自然播放跨入**才播（任务点1领取回合 / `StateEngine.IsNight(cur) && !IsNight(cur-1)` 的回合）；拖动进度条/跳转不会打断。播放即暂停回放、全屏盖住所有面板（sortingOrder 1000），播完自动恢复。
- **改哪个事件用哪个视频**：改常量 `ReplayCinematic.TASK1_VIDEO` / `NIGHT_VIDEO`（或 `ResolveVideo()` 的返回）。要**新增一类触发**：在 `ResolveVideo()` 加一条判定 + 一个视频常量即可。
- **WebGL**：必须 H.264/avc1；全平台 `audioOutputMode=Direct` 出声（动画默认关 → 需先点开「动画」按钮=一次用户手势，浏览器才允许带声自动播放；若个别浏览器仍拦截无声/首帧卡，可改回 `None` 静音保底）。分辨率建议 ≤1280×720；当前 10~14 Mbps 码率偏高（慢网首播要等），重压到 ≤4 Mbps 更流畅（非必需）。
- **BGM 音量**：游戏 BGM 默认静音（`BgmController.CurrentVolume` 默认 `Mute`），选手点「音量」按钮逐档恢复。
- **时长**：播一遍就关，任意时长都行（ReplayCinematic 播到结尾即收尾恢复）。

## 二、当前实现

### 1. 卡片 4 态（数据驱动）

`TaskBadgeManager` 每帧读 `player.data.rounds[cur-1].teams[].task`，与 `rounds[cur-2]` 做跳变检测判定状态：

| 状态 | 表现 | 触发（上一回合 → 当前回合） |
|------|------|------|
| Intro | claim.png 图片（至少 2 回合） | 有任务且 `roundCost == 0`（刚接任务那回合） |
| Working | working.mp4 循环播放（唯一视频） | 有任务未完成（稳态） |
| Success | unlock_success.png（2 回合后淡出销毁） | 上一回合有任务未完成 → 本回合 `isTaskComplete` |
| Fail | unlock_fail.png（2 回合后淡出销毁） | 上一回合有任务未完成 → 本回合任务消失且未完成 |

- 结果态（Success/Fail）播放中不受稳态 Hidden 打断，只有新任务（Intro/Working）能打断；2 回合后淡出由管理器销毁。
- 拖动进度条 / JumpTo：先全清卡片，再按目标回合数据重建。

### 1.5 两种任务点（按 taskType 区分）

| taskType | 任务点 | 显示 |
|----------|--------|------|
| `自进化类1` | 宝箱（game 14,14 / 23,14） | **全流程卡片**：claim 图 / working 视频 / unlock_success·unlock_fail 图 |
| `自进化类2` | 装甲车（game 17,17 / 26,17） | **纯文字小弹窗**（TradeBadge 风格：0.3 缩放、单位头顶、深色半透明底 + 黄字）：接受任务 → 正在修理中 → 修理成功/失败 |

- 区分逻辑：`TaskCardBadge.SetState` 里 `_textMode = (_taskType == "自进化类2")`；文字模式不走图片/视频，状态文字显示后 2 回合淡出（Success/Fail 同 RESULT_ROUNDS）。
- 管理器统计共享 working 播放时**跳过文字模式卡**（它不显示视频，避免空转解码）。

### 2. 渲染层（无中间态）

- **Intro / Success / Fail**：底板 `_MainTex` ← `Resources.Load("Sprites/xxx")` 静态图（`LoadTex` 懒加载缓存，同步、WebGL 安全）。图片自带字样，不叠文字。
- **Working**：底板 `_MainTex` ← **全局共享 working 视频 RT**。`TaskBadgeManager.EnsureSharedVideo(WORKING_VIDEO)` 游戏开始即 Prepare + 循环播放进共享 RenderTexture，Working 态立即可显示；本地 VideoSlot 仅作共享未就绪回退。
- **无中间态**：目标资源未就绪时保持当前画面不动，就绪后无缝接管；绝不蓝/白/空底。
- **2 回合展示**：Success/Fail 记录进入时的回合（`_resultStartCur`），`cur - start >= 2` 后淡出（round-based，速度无关、暂停冻结）。

### 3. 关键设计

- **外观**：`CARD_SCALE=4`（底板 4×2.4）；金黄描边随背景同步淡入淡出。
- **暂停冻结**：回放暂停时动画计时与 working 视频同步冻结（共享播放器由管理器统一 Pause/Play）。
- **只播当前显示的**：共享 working 仅在"有卡片处于 Intro（预卷）或 Working"时播放，空闲期暂停省解码（WebGL 并发解码是卡顿源，对齐 LycheeMap）。
- **定位**：锚点以开拓者血条上方 +0.5 净空计算，不受父节点缩放影响。
- **性能**：底板/描边共享 `Sprites/Default` 材质 + MaterialPropertyBlock + GPU Instancing。

### 4. WebGL 关键点

- **URL**：`TaskCardBadge.VideoUrl()` 生成相对正斜杠路径（剥 `http(s)://host`）。勿用 `Path.Combine`（反斜杠浏览器不认）。
- **编码**：working.mp4 必须 H.264/avc1，否则浏览器解不出帧。
- **autoplay**：working 播放器 `audioOutputMode=None`（静音放行）；`skipOnDrop=true` 实时跳帧。
- **就绪**：WebGL 上 `prepareCompleted` 可能不触发，用 `isPrepared` 轮询兜底。
- **视频内容建议**：≤960×540、低码率、30fps（与 60fps 整除避免抖帧）。
- **测试**：用 HTTP 服务器打开构建（`python -m http.server` / `npx http-server` / Unity Build & Run），勿 `file://` 双击。

### 5. 全屏剧情视频（ReplayCinematic，同入口挂载）

`ReplayCinematic` 与卡片管理器一样挂 ReplayEntry，纯数据驱动、每帧扫描回合数据，**自然播放跨入**以下回合才触发全屏：

| 触发 | 回合判定 | 视频 |
|------|----------|------|
| 任务点1领取 | 某队 `task.taskType=="自进化类1"` 且 `roundCost==0`、上回合该队无 | plane.mp4 |
| 入夜首回合 | `StateEngine.IsNight(cur) && !StateEngine.IsNight(cur-1)` | ufo.mp4 |

流程：`SetPlaying(false)` 暂停回放 → 全屏黑底 + 视频（Canvas sortingOrder=1000，盖过全部 UI 面板 200~500）→ 播完自动 `SetPlaying(true)` 恢复；锁存触发回合，避免同回合恢复后重复打断。拖动/跳转 paused 不触发。WebGL：URL 走 `TaskCardBadge.VideoUrl()`（相对正斜杠）、`audioOutputMode=None`、`isPrepared` 轮询兜底、Start 预热两视频。
