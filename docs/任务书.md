# 《荒野求生》v6.0 任务书

# 一、背景信息

- 云核心网编程大赛是面向云核心网研发管理部全员举办的一年一度大型软件竞赛，今年是云核心网第十届编程大赛。

- 在编程大赛的舞台，参赛人员可充分展示软件设计与编程能力，享受编码解题的乐趣，感受软件改变世界的魅力。

# 二、参赛要求

- 参赛组队要求：每队队员人数不超过3人。


# 三、游戏概述

- 每场比赛由两支参赛队伍同台竞技，无先后手区分
- 两个玩家的基地分别在地图的左上和右下区域，玩家需要控制角色，在白天采集、建造、做任务来升级防御工事，晚上通过防御工事抵御野兽的进攻，直到一方玩家基地被毁或打满10天为止，游戏结束
- 每场比赛进行两轮，分为上半场和下半场，下半场双方互换位置

- 整场比赛共用同一张地图，不同赛段的任务内容会动态变更。
- 以下元素均会阻挡角色移动：水、己方/敌方建筑（基地、武器工事、围墙）、己方/敌方角色、野兽、中立单位（小贩、武器商店）、4 个任务点、矿区。只有空地可以穿越移动。

## 4\.2 时间单位

- 游戏以回合为核心调度单位，每一回合同时调度双方所有角色执行操作。
- 游戏世界观中以天为单位，一天分昼夜，白天=80回合，晚上=50回合。
- 单场比赛最大回合数为1300回合（10天），达到上限则比赛自动结束。

## 4.3 局部视野

- 己方所有单位（武器工事、基地、围墙、角色）的视野距离均为4。处于己方视野范围内的敌方单位可见，超出视野范围则不可见；野兽为全图可见。

- 己方所有单位视野全局共享；敌方基地为全局可见单位，不受视野距离限制。

- 建造行为只能在白天使用，晚上不允许使用，其他行为不受限制。

### 4.5.4 移动与攻击

1. 两点之间的距离计算采用**切比雪夫距离**计算，即$max(|x_1-x_0|,|y_1-y_0|)$，例如加特林炮台攻击距离为4，覆盖下图黄色区域：

  ![image-20260728142848394](http://image.huawei.com/tiny-lts/v1/images/hi3ms/5e651eeb6b57020ae9b6d75ad45b360a_323x296.png)

2. 角色可朝8各方向进行移动，若没有障碍物阻挡，则可以移动到当前位置的周围8个位置，两个障碍物相邻的对角线位置不构成行进阻挡。

  ![image-20260728142903170](http://image.huawei.com/tiny-lts/v1/images/hi3ms/242885acdce9f2563966f0f0b63c59dc_649x227.png)

3. 武器攻击需要指定攻击目标位置，加特林炮台、电磁狙击炮攻击会产生攻击路径，攻击路径为两个坐标中心之间相连的直线，攻击路径示意图如下图所示，其中红色为主动攻击的角色位置，绿色为被攻击的对象
  ![image-20260818203252364](http://image.huawei.com/tiny-lts/v1/images/hi3ms/c5b13157c7a227dd847138c1d19a1919_427x422.png)

4. 武器攻击需指定攻击目标位置，attack 指令的 targetPos 为坐标数组（加特林传 N 个落点、电磁狙击炮/火箭发射台各传 1 个）。攻击会产生攻击路径，路径为炮台占地最近角格与目标点之间相连的直线。三种武器的弹道与伤害规则差异如下：

  - **加特林炮台**：攻击等级 LV1~5，发射与等级相同数量的子弹（1~5 颗），玩家须提供与等级数量相同的 N 个落点（targetPos 长度 = 等级）。所有落点须落在同一 90° 锥形内（任意两个落点相对炮台的方向夹角 ≤ 90°，否则整次攻击非法）。每颗子弹沿自身落点的弹道飞行，命中该弹道上最近的一只野兽即消耗，造成 20 伤害/颗（不穿透、不连锁）。任一落点超出射程 4、落点数 ≠ 等级、或锥形违例 → 整次攻击非法（不发射任何子弹）。弹道无野兽的子弹落空，不影响其余子弹与整次合法性。
  - **电磁狙击炮**：玩家提供 1 个落点（终点）。能量 = 25 × 等级（LV1=25/LV2=50/LV3=75/LV4=100/LV5=125）。电磁能量沿弹道穿透：路径上每只存活野兽受 min(剩余能量, 该兽当前血量) 伤害，能量按造成的伤害量扣减；能量耗尽或到达终点即止。不被墙/建筑/角色物理阻挡，仅被路径上的野兽消耗能量。射程 7。落点数 ≠ 1 或超射程 → 攻击非法。
  - **火箭发射台**：玩家提供 1 个落点。无弹道、无视阻挡、全图可达。仅伤害野兽与敌方围墙（不伤敌方塔/基地/角色，不伤己方/中立）。中心伤害 = 50 × 等级；落点周围 8 格（3×3 去中心）溅射 = 中心伤害的 50%（= 25 × 等级）。发射后进入 3 回合冷却空窗（R+1/R+2/R+3 不可再发，R+4 可再发）。落点数 ≠ 1 或处于冷却 → 攻击非法。

5. 武器攻击等级上限为 LV5，无激光模式。

5. 当己方被调度，己方角色之间发生碰撞时，发生碰撞的角色待在碰撞前的位置不再行走直到下一回合才被调度。

6. 当己方被调度，己方角色和敌方角色之间发生碰撞或撞击到障碍物或野兽时，该角色再当前回合内，待在碰撞前的位置不再行走直到下一回合才被调度。

## 4.6 中立单位信息

整个世界的中立单位为小贩与武器商店（中立单位无敌）；另有 4 个团队专属任务点（挑战者方 2 个、防守者方 2 个），仅本队开拓者可领取任务，详见第五章《任务》。

### 4.6.1 小贩

玩家可通过将石头/铁/铜贩卖给小贩来赚取金币，而卖给小贩的矿石价格会随着世界新闻的内容而发生变化，初始情况下的贩卖金额如下：

| 矿石 |   基准价    |
| ---- | :---------: |
| 石头 | 1 金币/单位 |
| 铁   | 3 金币/单位 |
| 铜   | 5 金币/单位 |

可通过指令中的 `num` 字段批量贩卖（如 `num: 3` 一次卖出 3 块矿石），`num` 缺失时默认为 1；矿石数量不足时整笔贩卖失败。

### 4.6.2 任务点

地图上有 4 个团队专属任务点（`challengerTaskPoint1`/`challengerTaskPoint2`/`defenderTaskPoint1`/`defenderTaskPoint2`，坐标对角对称）。开拓者在己方任务点周围一格内 `executeTask` 领取任务，赚取积分与金币，详见第五章《任务》。任务点仅对本队开拓者开放；在他方任务点 `executeTask` 不予执行（仅记指令错误，不计队伍异常）。

### 4.6.3 武器商店

角色可通过金币购买武器商店内的物品，武器商店售卖的物品信息与金额如下：

**建筑升级券：**

升级券买入后存入背包，使用 `use` 指令消耗 1 张生效。`use` 不携带 `num` 字段，每条 `use` 固定消耗 1 张；`buy`/`sell` 可用 `num` 批量（详见下文消耗品注）。

| 商品                  | 效果                                                       | 金额 |
| --------------------- | ---------------------------------------------------------- | ---- |
| WeaponUpgradeVoucher  | 目标武器攻击等级 +1 且最大 HP 永久 +10% 基础值 | 25   |
| WallUpgradeVoucher    | 己方全体围墙最大 HP 永久 +10% 基础值  | 25   |
| StationUpgradeVoucher | 己方基地最大 HP 永久 +10% 基础值                           | 25   |

注：

- 武器升级券、基地升级券需使用英雄与目标建筑相邻（切比雪夫距离 ≤1）方可生效，须在 `use` 中携带 `targetPos` 指定目标建筑；围墙升级券忽略 `targetPos`，对己方全体围墙生效。
- 武器的攻击表现会随着等级提升而发生变化，攻击等级上限为 LV5（无激光模式），其中：

  - 加特林炮台：等级 LV1~5，发射与等级相同数量的子弹（1~5 颗，须提供等量落点且落在 90° 锥内），每颗子弹 20 伤害
  - 电磁狙击炮：能量 = 25 × 等级（25/50/75/100/125），沿弹道穿透消耗能量
  - 火箭发射台：中心伤害 = 50 × 等级，3×3 溅射 = 中心 50%（= 25 × 等级），发射后 3 回合冷却

  其中攻击机理详见4.5.4章节
- 武器攻击等级已达 LV5 时，使用武器升级券将失败且**不消耗**该券（券仍留在背包）。
- 目标武器已被摧毁或不存在时，使用失败且不消耗券。
- 升级最大 HP（按基础值 10%）时当前血量同步等额抬高，例如围墙基础值 600、当前 HP 400，升级后最大 HP 660、当前 HP 460。
- 基地、武器工事、围墙的最大 HP 均可通过对应升级券升级，每次 +10% 基础值。

**消耗品：**

## 4.7 昼夜与兽潮

### 4.7.1 昼夜

白天玩家需要负责控制工人进行采集、建造活动，并通过贩卖矿石获取金币，到武器商店升级建筑；此外，控制开拓者做任务也可获得额外积分与金币，夜晚会出现成群野兽，晚上玩家需要控制3个角色操控武器工事防守兽群。

### 4.7.2 野兽种类

| 野兽 | 攻击力 | 攻击距离 | HP   | 积分 |
| ---- | ------ | -------- | ---- | :--: |
| 小型 | 5      | 3        | 20   |  1   |
| 中型 | 10     | 3        | 40   |  2   |
| 大型 | 20     | 3        | 200  |  4   |
| BOSS | 40     | 3        | 1000 |  10  |

> 攻击距离 = 3（切比雪夫距离），即野兽可对距自身 ≤3 格的围墙/防御塔/基地/角色造成伤害；攻击力为单次攻击伤害。所有野兽攻击距离相同，与野兽种类无关。

### 4.7.3 野兽行为

**刷新与目标：**

- 所有的野兽会在夜晚的第一个回合统一出现。

- 以y=x对角线为界，将地图划分成2块区域，每个区域内野兽生成数量相同，生成位置随机，但不会生成在玩家可建造区域内。

- 野兽的攻击目标是区域内玩家的基地。

**距离与射程：**

- 野兽两点间距离与攻击距离均采用**切比雪夫距离** $max(|x_1-x_0|,|y_1-y_0|)$。
- 所有野兽的**攻击距离 = 3**（切比雪夫），即可对距自身 ≤3 格的围墙/防御塔/基地/角色造成伤害；攻击不分敌我阵营，"谁挡打谁"。

**寻路与障碍：**

- 野兽刷新后，立即用 A*（8 方向）计算一条从刷新点到目标基地的最短路径作为移动路线，每回合沿路径前进一格。
- 寻路将以下格子视为**不可通行障碍**：水、矿区、中立单位（小贩、武器商店、4 个任务点）。中立单位不可穿过且**无敌**，野兽不会攻击它们。围墙、防御塔、基地、角色在野兽寻路图中视为可通行——野兽沿直线推进，遇到时改为攻击。

**每回合移动/攻击级联（对每只野兽按 id 升序依次判定）：**

1. **寻路优先**：野兽优先沿路径移动。当路径下一格（距离 1）被**敌方**阻挡（围墙/防御塔/基地/角色）时，改为攻击该阻挡物。
2. **被自家野兽阻挡**：当下一格被另一只野兽占据时，先沿移动路径前方、切比雪夫 ≤3 的格子寻找可攻击敌方；找到则原地攻击（不绕行）。
3. **重新寻路**：若步骤 2 路径前方无可攻击对象，则将自家野兽作为阻塞点重新搜索路径；若绕行首格被敌方占据（不可通行）则攻击该格，否则沿新路径移动。
4. **全向扫描**：若仍搜索不到任何路径，则在全方向攻击范围（切比雪夫 ≤3）内寻找最近的敌方并攻击。
5. **放空**：若攻击范围内仍无任何目标，本回合原地不动（什么都不做）。

> 步骤 1 的"敌方阻挡"指路径下一格（距离 1）；步骤 2/4 的扫描范围为攻击距离 3。多目标取舍：取切比雪夫距离最近者，距离相同取角色 id 最小者（确定性）。

**其他规则：**

- 黑夜结束后，在第二天早上的第一个回合，残余野兽自动清除。
- 购买的野兽召唤令将会叠加在基础兽潮之上。

## 5.1推理类

【官方消息】报导的突发事件会引起供需关系发生变化，进而影响玩家与小贩之间的交易价格。

**示例：**

```
【官方消息】：
"矿业管理局紧急通报：北部铁矿区昨夜发生严重矿井塌方事故，主巷道结构受损，部分作业面被掩埋。安全监察部门已下达通知：为保障矿工安全，矿区将于明日
全面停工，进行巷道加固和主矿脉修复。矿区领班表示：'今天浅层矿面还能抢采一些，明天的全面停工不可避免。'工程队评估：类似规模的塌方事故，修复工程通常需要2天左右才能完成并恢复开采。"
小贩表示：在铁矿紧缺时，收购铁矿价格会变成原来的4倍
```

对游戏影响：

- 当天：铁矿采集不受影响。
- 明天+后天：铁矿无法采集，无法产出铁资源，同时由于铁的稀缺，小贩回收铁的价格上涨：3金币/单位→12金币/单位。
- 大后天及之后：铁矿恢复可采集，小贩回收铁的价格恢复到3金币/单位。

# 六、积分规则

$$\text{总积分} = score_1 + score_2 + score_3$$

**$score_1$ — 任务完成积分（任务完成时）**：

$$score_1 = \text{任务积分奖励} \times \frac{\text{任务标准回合数}}{\text{实际完成回合} - \text{接取回合}}$$

**$score_1$ — 部分完成积分（任务部分完成时）**：

$$score_1 = \text{任务积分奖励} \times \text{通过率}$$

> 通过率 = 已完成子任务数 / 总子任务数。

**$score_2$ — 作战击杀积分**：

| 野兽类型    | 积分/只 |
| ----------- | :-----: |
| 小型兽      |    1    |
| 中型兽      |    2    |
| 大型/精英兽 |    4    |
| BOSS        |   10    |

$$score_2 = \sum (\text{野兽击杀数} \times \text{野兽积分})$$

**$score_3$ — 生存天数积分**：

$$score_3 = \sum_{day=1}^{10} 10 \times day \times \text{存活系数}$$

- 存活系数 = 1（基地未被摧毁），= 0（基地被摧毁当天及之后）

# 七、胜负判定

1. 结果判定
   - 比赛双方异常响应均达到5次。
   - 1300个回合全部结束。

   - 双方基地均被完全摧毁。
2. 胜负判定
   - 每局比赛分为上半场和下半场，每半场换边对战，均获得胜利的一方为最终胜利方，双方均获得一场胜利则按照上半场和下半场两场对得分总和进行比较，得分高的为胜利方，得分相同为平局。
   - 每半场对战，一方基地被摧毁，则另一方直接获得半场游戏胜利。若双方基地在同一回合被同时摧毁，则判定为平局；若双方基地在不同回合先后被摧毁，则先被摧毁的一方判负、另一方获胜。若半场游戏结束后基地未被摧毁，根据第六章《积分规则》计算积分，积分高者获胜。
3. 总积分判定
   - 胜一局积3分，平局双方各积1分，失败积0分。

# 八、异常处理

异常响应特指参赛代码触发的异常，包含以下三类：

1. 请求响应超时：建立连接过程超过10秒判超时；连接建立并发送请求后，5秒内未收到响应判超时。

2. 响应格式错误：返回数据格式不符合《参赛接口文档规范》。

3. 指令错误：发送指令标识无法识别、指令非法。

异常处理机制：

- 单队异常响应累计达到5次，后续回合不再调度该队伍代码，直至比赛结束。

- 参赛代码异常退出后，不会自动重启拉起。
