# 一、背景信息

- 云核心网编程大赛是面向云核心网研发管理部全员举办的一年一度大型软件竞赛，今年是云核心网第十届编程大赛。

- 在编程大赛的舞台，参赛人员可充分展示软件设计与编程能力，享受编码解题的乐趣，感受软件改变世界的魅力。

# 二、参赛要求

- 参赛组队要求：每队队员人数不超过3人。


# 三、游戏概述

- 每场比赛由两支参赛队伍同台竞技，无先后手区分
- 两个玩家的基地分别在地图的左上和右下区域，玩家需要控制角色，在白天采集、建造、做任务来升级防御工事，晚上通过防御工事抵御野兽的进攻，直到一方玩家基地被毁或打满10天为止，游戏结束
- 每场比赛进行两轮，分为上半场和下半场，下半场双方互换位置

## 4\.2 时间单位

- 游戏以回合为核心调度单位，每一回合同时调度双方所有角色执行操作。
- 游戏世界观中以天为单位，一天分昼夜，白天=80回合，晚上=50回合。
- 单场比赛最大回合数为1300回合（10天），达到上限则比赛自动结束。

## 4.3 局部视野

- 己方所有单位（防御塔、基地、围墙、角色）的视野距离均为4。仅处于己方视野范围内的敌方单位与野兽可见，超出视野范围则不可见。

- 己方所有单位视野全局共享；敌方基地为全局可见单位，不受视野距离限制。

## 4.7 昼夜与兽潮

### 4.7.1 昼夜

白天玩家需要负责控制工人进行采集、建造活动，并通过贩卖矿石获取金币，到武器商店升级建筑；此外，控制开拓者做任务也可获得额外积分与金币，夜晚会出现成群野兽，晚上玩家需要控制3个角色操控防御塔防守兽群。

### 4.7.2 野兽种类

| 野兽 | 攻击 | HP   | 积分 |
| ---- | ---- | ---- | :--: |
| 小型 | 20   | 40   |  1   |
| 中型 | 40   | 100  |  2   |
| 大型 | 70   | 250  |  4   |
| BOSS | 120  | 1000 |  10  |

### 4.7.3 野兽行为

**刷新与目标：**

- 所有的野兽会在夜晚的第一个回合统一出现。

- 以y=x对角线为界，将地图划分成2块区域，每个区域内野兽生成数量相同，生成位置随机，但不会生成在玩家可建造区域内。

- 野兽的攻击目标是区域内玩家的基地。

**野兽移动与攻击：**

- 野兽刷新后，立即计算一条从刷新点到目标基地的最短路径，作为移动路线。
- 野兽只会攻击阻挡它移动的路径上的建筑/角色。

**其他规则：**

- 黑夜结束后，在第二天早上的第一个回合，残余野兽自动清除。
- 购买的野兽召唤令将会叠加在基础兽潮之上。

## 4.8 世界新闻

每个白天的第一个回合，系统都会发布世界新闻，分为两大板块：

1. 官方消息：该世界中出现的突发消息，可能会导致玩家贩卖给小贩的矿石价格发生波动，详见第五章《任务》5.1章节。
2. 民间传闻：该世界中民间流传的一些传闻，玩家需要根据传闻来获取宝藏，详见第五章《任务》5.2章节。

# 五、任务

双方有3类任务，通过2种方式获取：

| 通道 | 任务类型 | 交互方式 |
|------|---------|---------|
| **世界新闻** | 推理类、长上下文 | 新闻被动获取 |
| **任务官** | 自进化类 | 任务官主动领取 |

其中任务官主动领取的任务，在任务执行结束后，刷新间隔为30个回合，以下行为都会视为任务结束：

- 任务被完成。
- 从领取任务起开始技术，计数回合超过了最大任务执行回合数20回合。

完成任务后，会获得相应的积分和金币，积分计算方式参考第六章《积分规则》，金币计算方式为任务金币奖励*通过率。

## 5.1推理类

【官方消息】报导的突发事件会引起供需关系发生变化，进而影响玩家与小贩之间的交易价格。

**示例：**

```
【官方消息】：
"矿业管理局紧急通报：北部铁矿区昨夜发生严重矿井塌方事故，主巷道结构受损，部分作业面被掩埋。安全监察部门已下达通知：为保障矿工安全，矿区将于明日
全面停工，进行巷道加固和主矿脉修复。矿区领班表示：'今天浅层矿面还能抢采一些，明天的全面停工不可避免。'工程队评估：类似规模的塌方事故，修复工程通常需要2天左右才能完成并恢复开采。"
```

对游戏影响：

- 当天：铁矿采集不受影响。
- 明天+后天：铁矿无法采集，无法产出铁资源，同时由于铁的稀缺，小贩回收铁的价格上涨：2金币/单位→4 金币/单位。
- 大后天及之后：铁矿恢复可采集，小贩回收铁的价格恢复到2金币/单位。

## 5.2 长上下文类

【民间传闻】记录着市井消息，玩家需要提取关键信息，获取宝藏。

**示例：**

```
DAY1: 【民间传闻】：情报1
DAY2: 【民间传闻】：情报2
...
DAYN：【民间传闻】：情报N
```

玩家需要根据情报1~情报N消息，找到关键信息，获取宝藏，宝藏藏有大量积分与金币。

## 5.3 自进化类

开拓者前往任务官接取自进化类任务，根据任务官任务需要，与沙盒环境进行交互，最终提交答案信息，指令详见接口文档

**示例：**

```
给你一个三方的天气查询API接口文档，让你通过该API查询天气：
任务1：请查询北京天气
任务2：请查询上海天气

```

玩家需要根据任务1探索的内容，形成固定SOP或者SKILL，实现Agent自进化，进而快速做出后续任务。

# 六、积分规则

$$\text{总积分} = score_1 + score_2 + score_3 + score_4$$

**$score_1$ — 任务完成积分**：

$$score_1 = \text{任务积分奖励} \times \frac{\text{任务标准回合数}}{\text{实际完成回合} - \text{接取回合}}$$

**$score_2$ — 部分完成积分**：

$$score_2 = \text{任务积分奖励} \times \text{通过率}$$

> 通过率 = 已完成子任务数 / 总子任务数。

**$score_3$ — 作战击杀积分**：

| 野兽类型    | 积分/只 |
| ----------- | :-----: |
| 小型兽      |    1    |
| 中型兽      |    2    |
| 大型/精英兽 |    4    |
| BOSS        |   10    |

$$score_3 = \sum (\text{野兽击杀数} \times \text{野兽积分})$$

**$score_4$ — 生存天数积分**：

$$score_4 = \sum_{day=1}^{10} 10 \times day \times \text{存活系数}$$

- 存活系数 = 1（基地未被摧毁），= 0（基地被摧毁当天及之后）

# 七、胜负判定

1. 结果判定
   - 比赛双方异常响应均达到5次。
   - 1300个回合全部结束。

   - 任意一方基地被完全摧毁。
2. 胜负判定
   - 每局比赛分为上半场和下半场，每半场换边对战，均获得胜利的一方为最终胜利方，双方均获得一场胜利则按照上半场和下半场两场对得分总和进行比较，得分高的为胜利方，得分相同为平局。
   - 每半场对战，一方基地被摧毁，则另一方直接获得半场游戏胜利。若半场游戏结束后基地未被摧毁，根据第六章《积分规则》计算积分，积分高者获胜。
3. 总积分判定
   - 胜一局积3分，平局双方各积1分，失败积0分。

# 八、异常处理

异常响应特指参赛代码触发的异常，包含以下三类：

1. 请求响应超时：单次请求至响应时长超过5秒。

2. 响应格式错误：返回数据格式不符合《参赛接口文档规范》。

3. 指令错误：发送指令标识无法识别、指令非法。

异常处理机制：

- 单队异常响应累计达到5次，后续回合不再调度该队伍代码，直至比赛结束。

- 参赛代码异常退出后，不会自动重启拉起。
